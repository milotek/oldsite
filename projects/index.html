nixeljam

2025 - now

My NixOS config. One flake, every machine, one colour.

Built on top of anotherhadi/nixy, with my own theme layer, hosts and server modules bolted on.

The whole desktop is repainted from one base16 scheme in themes/. Change the accent in one file and Hyprland, waybar, the terminal, neovim and the GTK apps all follow. The pink you are looking at right now is base0D out of themes/pixeljam.nix.

Lockyn

2024 - now

A studying app for GCSE and sixth form students. Unreleased, source is private.

Cross platform, one codebase: iOS, Android, web and desktop. React Native on the front, Firebase on the back because the data is document-shaped and I did not want to run a database at 17.

It started life as my A level NEA and got rewritten properly afterwards. The UI is the part I care about most; every screen went through a few passes before it stopped annoying me.

AutoPet feeder

2024

An automatic pet feeder, designed and built to a client's spec. The client was my neighbours.

Raspberry Pi, a servo, a touchscreen and USB-C in, so there is exactly one cable. Shell is 3D printed ABS with an oak finish, because a plastic box on someone's kitchen floor is still a thing they have to look at every day.

Ran the whole thing properly: client spec, cardboard prototypes, feedback rounds, an evaluation. The design document is the part I am actually proud of.

MakersBNB

2025

An AirBnB clone built by six of us in a week, test-first the whole way.

Flask and Basecoat UI, Postgres underneath, pytest and Playwright on top. Team of six.

The interesting part was not the app, it was six people agreeing on an architecture on day one and it still holding on day five. List a space, request a booking, approve or decline it.

habits

2026

A habit tracker that renders as a GitHub contribution grid, for a screen on my wall.

Kotlin. It runs on a tablet stuck to a wall, so the entire interface is one grid and nothing else. If a habit tracker needs a login screen it has already lost.

I have tried about six of these apps and given up on all of them, always for the same reason: opening an app to tick a box is more effort than the box is worth. This one is already on, already showing, and one tap wide. Green square or no green square.
