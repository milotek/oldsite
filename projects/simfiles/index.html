notITG modcharts

A small pack of StepMania modcharts. Lua for the choreography, GLSL when Lua runs out.

  • lua
  • glsl
  • rhythm games

source

I like rhythm games and I like Lua, so I started charting. A modchart is a Lua program that abuses the playfield in time with the music, with shaders on top for the bits Lua can't reach.

Three songs so far, varying wildly in quality. I don't own a dance pad, which should tell you exactly how these were tested.
