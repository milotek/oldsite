A habit tracker for a tablet bolted to the wall in my flat. It renders the year as a GitHub style activity grid, because that's the one progress visualisation I've ever actually looked at twice.

Kotlin. There's a matching module in my NixOS flake that serves it, so the kiosk is declared in the same place as the rest of the house.

Deliberately shit in scope: no streaks, no notifications, no account. Squares or no squares.
