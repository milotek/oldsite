CarSwap

2025 · tool · released

A Lua script for GTA Online that lets you drive the unreleased DLC cars as if they were normal ones.

luagtamodding
Repo

Rockstar ships cars into the game files months before they unlock them. CarSwap maps a locked model onto a car you already own, so the game treats it as legitimate.

Written for the Stand menu. There's a matching theme in another repo, which is terrible but stylish.
