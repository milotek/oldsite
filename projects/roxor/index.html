Roxor Engine

A base project for Roblox games that want to feel grounded. Character controller, weapons, downed and revive, and gore you can switch off.

Every Roblox game we started was rebuilding the same movement and combat code, badly, so we stopped and built it once.

Roxor is the shared base: a character controller that actually feels like something, melee and gun systems, health and stamina with a downed and revive state, characters that flinch when shot and ragdoll when they don't get up. The aesthetic target is Source engine rather than Roblox default, which mostly means restraint.

Written in Luau under Pixeljam Studios.
