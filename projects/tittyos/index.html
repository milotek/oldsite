tittyos

2025 · library · wip

A deep learning library in C++. Tensors, shapes, dtypes and a working backward pass.

c++machine-learningautograd
Repo

Built with Samuel Johnson. Tensors carry a shape and a dtype, ops build a graph, .backward() fills in the gradients.

ty::Tensor result = ty::sum(ty::multiply(tensor1, tensor2));
result.backward();
tensor1.grad(); // [2.0, 3.0, 5.0, 7.0, 11.0]

Still under development, and the name is not up for discussion.
