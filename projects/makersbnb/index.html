An Airbnb clone built by six of us in a week, test first, with the tests actually driving it.

List a space, request a booking, approve or decline it, and don't double book. Flask on the back, Basecoat UI on the front, Playwright driving a real browser for the feature tests.

Six people on one codebase for a week is the actual lesson here. The code is fine; the interesting part was keeping six branches from turning into a merge nightmare.
