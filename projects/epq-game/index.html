EPQ platformer

An accessibility-focused platformer, built over six months of weekends for my Extended Project Qualification.

Notes

The brief I set myself was a platformer that stays playable if you can't hear it, can't see colour differences, or can't hit a two-frame input window. That constraint shaped the level design far more than I expected it to.

The protagonist doesn't speak, which is deliberate. Valve do the same thing and it works for the same reason: nothing the character says can contradict what you'd have said.
