My NixOS config. Four machines, one flake, one theme file that everything reads from.

nixnixoshyprlanddotfiles
Repo

Started as a fork of nixy and has drifted a long way since.

It runs my desktop, a mini PC that serves files, a VPS, and my work Mac, off one modular flake. Hyprland, Waybar, tofi, swaync, Ghostty, Neovim through nvf, all declared.

The bit I actually care about is themes/pixeljam.nix. One attrset holds the colour scheme, the rounding, the gaps, the border widths and the fonts. Change the accent in that file and GTK, the bar, the terminal, Neovim and the lock screen all move together on the next rebuild.
