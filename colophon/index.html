Colophon

Static HTML, generated by one Python script with no dependencies outside the standard library. Content is TOML and Markdown in content/; the script reads it and writes the pages out. No JavaScript runs on any page.

The layout is a drawing sheet. Frame, ruler, sheet numbers, a title block in the corner with the fields an engineering drawing carries. Projects sit on it as plates with part numbers.

Type is MesloLGS Nerd Font for anything that behaves like a label and Source Sans 3 for prose, both subset to Latin and served as woff2 from this domain. They're the same two faces my desktop uses.

Colours are Catppuccin Mocha with #ffbdbd as the only accent, lifted straight out of the base16 scheme in my NixOS config. Nothing else is allowed to be bright.

Images are WebP. The gallery loads thumbnails and only fetches the full file when you open one.

Hosted on GitHub Pages. Source is in the repo linked in the footer, and the first post has the longer version.
