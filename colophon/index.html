Colophon

How this thing is put together, for the three people who care.

Static HTML, generated by one Python script with nothing but the standard library behind it. Content is Markdown with front matter and a couple of TOML files, so adding a project or a post means adding a file, not editing a template. Posts can come straight out of my Obsidian vault untouched.

No JavaScript. No build tooling beyond python3 build.py. Output is committed and served by GitHub Pages.

Colours are Catppuccin Mocha with #ffbdbd on top, which is the same accent my desktop uses. Type is Source Sans 3 and JetBrains Mono, both self-hosted.

Every drawing is mine. The 88x31 buttons below are not, and came from the 88x31 archive.
