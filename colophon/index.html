Colophon

Static HTML. No framework, no third-party requests, no analytics, no cookies.

build.py reads TOML and Markdown out of content/ and writes the whole site. Adding a project is six lines of TOML, adding a post is a .md file. One Python file, standard library only.

Search runs off index.json, which is generated from the same data as the pages, so it can't drift.

Catppuccin Mocha, accent #ffbdbd. Source Sans 3 and JetBrains Mono, self-hosted.

The 88x31 buttons are drawn by tools/make-buttons.py from a TOML file, using a 5x8 bitmap font with anti-aliasing off.

Hosted on GitHub Pages. The repo is the site.

the numbers

  • 22 projects, 1 post, 15 drawings, 8 buttons.
  • One Python file, no dependencies.
  • Fonts, images and scripts all served from this repo. Nothing phones home.
