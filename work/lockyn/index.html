Product

Lockyn

A commercial study app for GCSE and sixth form students. React Native front end, Firebase behind it.

A study and focus app for students sitting GCSEs and A levels. You set a daily goal, start a timer, and it tracks where your screen time actually went instead of where you think it went.

Front end in React Native and TypeScript so iOS and Android share a codebase. Firebase for auth and storage.

It started life as my A level NEA, which meant I couldn't release it until after results day. The design work is the part I'd defend: it's a productivity app for teenagers, so if it feels like homework it's dead on arrival.
