.NET Game Collection

Battleships, Tetris and Blackjack in C#. One text-based, one terminal GUI, one WinForms.

GitHub

Three games at deliberately increasing difficulty, to show the process rather than just the result. Battleships is text-based, Blackjack runs as a terminal GUI, Tetris is WinForms with an actual render loop.

Shipped with a 14 page written evaluation, which at the time felt like homework and in hindsight was the useful bit.
