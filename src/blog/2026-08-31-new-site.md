This is the third version of milotek.dev.
The first was a Carrd page.
The second was a React rewrite of that Carrd page, which fixed the content and left the design where it was.
This one is a rebuild of both.

## What went

The Carrd export had my phone number in plain text on the landing page, a `mailto:` pointing at the wrong TLD, Google Analytics, and the Adobe PDF viewer SDK with a client id hardcoded into the markup - all of that to render a PDF that every browser already renders.
Every project link went through `pixeljammed`, an account that is now a zero-repo placeholder, so they only resolved through GitHub's rename redirects.

All of that is gone.
The gallery also had one string doing duty as both the alt text and the visible caption, which is why every caption used to read like alt text.
Those are separate fields now.

## What stayed

The artwork, all sixteen pieces.
The pet feeder, the C# games, the EPQ platformer.
The comparison table under [other stuff](/misc), which is the only part of the original with a voice and would have been the easiest thing to quietly drop.

## The grid

The background is a canvas.
The cursor lifts the cells near it toward the accent colour, drags a short wake behind it, and clicking sends a ring outward.

The obvious way to build that is a `<div>` per cell, which on a normal laptop screen is about 1,700 of them, restyled sixty times a second.
That is a lot of work for a background.
Instead the dim lattice is rasterised once into an offscreen canvas and blitted each frame, and only the cells that are actually lit get stroked - bucketed by brightness, so a frame is six paths rather than several hundred.

If you have reduced motion turned on you get the lattice and nothing else.
If JavaScript never runs you get a CSS gradient version of the same grid, which is why the page is never blank while it boots.

## Colours

Catppuccin Mocha, with `#ffbdbd` standing in for maroon.
Catppuccin ships three surface steps and three overlay steps.
A layout made of stacked bordered panels needs more separation than that between "panel", "panel on panel", and "the border of a panel on a panel", so the scale here runs to seven surfaces and four overlays, interpolated between the real palette entries.

The design owes an obvious debt to [bomberfish.ca](https://bomberfish.ca), whose source is public and worth reading.
