Built from TOML and Markdown by one Python script, standard library only. One stylesheet. No JavaScript.

Colours are Catppuccin Mocha with `#ffbdbd` as the single accent, lifted from the pixeljam theme in my NixOS flake.

Type is Montserrat for sticker titles and Source Sans 3 for everything else, the same two fonts my desktop uses, self-hosted here.

The drawings are mine. The fox sticker is from my own files and I owe its artist a credit.

The classic 88x31 buttons come from the [cyber.dabamos.de](https://cyber.dabamos.de/88x31/) collection.

Hosted on GitHub Pages. [Source is on GitHub](https://github.com/milotek/wst4), and the [feed is RSS](feed.xml).
