# how it is made

Static HTML, generated by one Python script with no dependencies. Content is TOML and
Markdown in `content/`. Run `python3 build.py`, commit what falls out, GitHub Pages serves
plain files. There is no framework to migrate off in two years.

Adding a project means adding a `[[project]]` table. Adding a post means dropping a `.md`
file in `content/posts/`. Neither touches a line of code, which is the whole point.

# the look

It is my desktop. Windows with title bars, gaps between them, a status bar along the top,
and number keys that switch workspace. Hover a window and it takes the focus border, same
as Hyprland does.

The palette is Catppuccin Mocha, lifted out of `themes/pixeljam.nix` in my NixOS config,
with `base0D` swapped for `#ffbdbd`. Rounding, gaps and border widths come from the same
file. If I repaint my desktop I can repaint this in one variable.

# the type

Source Sans 3 for reading, JetBrains Mono for anything structural. Both self-hosted, so
the page makes zero third-party requests. No analytics, no cookies, no consent banner to
click through.

I would rather have used MesloLGS, which is what my terminal runs, but it is not on Google
Fonts and I was not about to ship a Nerd Font patch to a website.
