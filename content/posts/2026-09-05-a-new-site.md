The site this replaces was a Carrd page I exported in 2024 and then never updated. It had four projects on it, two of which I'd stopped caring about, and a section that still said "to be released 2026" long after the deadline had gone past. Fine for what it was. Not fine now.

So: this. Static HTML, generated by a single Python script with no dependencies. Every project is a Markdown file with front matter in `content/projects/`. Every post is a Markdown file in `content/posts/`. The art gallery and the buttons are TOML lists. Adding something means writing a file, which is the whole point, because the last site died the moment updating it felt like work.

The front matter is deliberately plain YAML, the sort Obsidian writes by itself. My notes already live in a vault in git, so a post can go from the vault into `content/posts/` without me editing anything.

There's no JavaScript on any page. There's no bundler, no framework, no lockfile. `python3 build.py` writes the HTML next to the sources and GitHub Pages serves it. If you ask me in five years to change a colour, I'll be able to.

Colours are Catppuccin Mocha with #ffbdbd over the top, which is what my desktop looks like, so at least the two things match now.

Source is [on GitHub](https://github.com/milotek/wst22) if you want to see how ugly the generator is.
