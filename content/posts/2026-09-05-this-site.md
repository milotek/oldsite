My old site was a Carrd export. It did the job in 2024 and then it just sat there going quietly out of date, still showing off projects I'd stopped caring about.

So this one is built to be edited. Every project is a markdown file in `content/projects/`. Every post is a markdown file in `content/posts/`. The drawings are a list in `content/art.toml`. Adding something never means touching code.

The generator is one Python file, `build.py`, with a small markdown renderer sat next to it. No dependencies, no lockfile, no `requirements.txt`. You run `python3 build.py` and it writes plain HTML into the repo root, which is exactly what GitHub Pages hands out. If PyPI fell over tomorrow this would still build.

There's no JavaScript on any page, because none of it needed any. One stylesheet, colours lifted from my desktop theme (catppuccin mocha, with `#ffbdbd` doing most of the work), and whatever fonts your machine already has.

The part I'd defend hardest is that markdown renderer, because writing your own is normally daft when there's a perfectly good library a `pip install` away. The whole point here is that it builds anywhere, forever, from a bare `python3`, and a dependency is the one thing that can quietly take that away. 200 lines felt like a fair price.

So if something on here is out of date now, that's on me rather than the tooling.
