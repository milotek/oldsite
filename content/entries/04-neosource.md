A Pixeljam Studios project. The goal is a base layer that feels like Source to build on, without the 2004
era tooling you sign up for by actually using Source.

It's a port of Fragsurf onto Unity 2022.3 and URP 14, plus the work to make the Linux editor usable. BSP
loading, surf and bhop movement, a speedrun timer, mapping tools, combat surf.

The whole thing is built to be modded. Most of the code is meant to be readable by people who want to take
it apart, which is how I learned Source in the first place.

Repo is private for now.
