An AirBnB clone built by six of us during the Makers bootcamp. List a space, request a booking, approve or reject it, manage your reservations.

Flask on Postgres, Basecoat UI on the front, pytest and Playwright for the tests. We wrote the tests first, which sounds like a thing you say on a CV until you've watched a six-person team break each other's code for a fortnight.

Getting six people to agree on a schema is harder than any of the code was.
