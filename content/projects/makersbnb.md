A group project from the Makers software engineering bootcamp. Six of us, Postgres underneath, pytest for units and Playwright driving a real browser for the feature tests.

Users can list spaces with a nightly price, request to book them, and approve or reject the requests that come in. The brief we set ourselves: clean architecture, TDD, and a UI that didn't look like a bootcamp project (hence Basecoat).
