A study app for GCSE and sixth-form students: focus timer, daily goals, screen-time summaries. React Native and TypeScript on the front, Firebase behind it, one codebase for iOS, Android and web.

It began as my A level Computer Science NEA, which is why it sat gated behind results day. The first prototype was SwiftUI; the rewrite was React Native so it could run on more than my own phone. Release date is "when it's good".[^1]
