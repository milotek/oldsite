An automated pet feeder, designed and built end to end: enclosure, electronics, firmware, touchscreen UI, scheduling.

A Raspberry Pi, a servo, a hopper, a JavaScript service with MQTT for the events, all in a 3D printed ABS shell with an oak facing so it looks like furniture rather than a science project. USB-C in, touchscreen on the front.

My A level Product Design project, so it came with a real client (my neighbours), a real spec and a written evaluation of whether it met it. The [design document](https://github.com/milotek/petfeeder/blob/master/Product%20Design%20NEA%20Edited.pdf) has the prototypes, the client interviews and the bits that went wrong.

It has been feeding a cat for two years, which is a better test than anything I could have written.
