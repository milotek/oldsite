Fragsurf is a surf and bunnyhop game built on Unity, and its source is open. It was also pinned to an old Unity version with a render pipeline that had moved on and an editor that would not open on Linux, which is a problem when Linux is what I use.

So the port: Unity 2022.3, URP 14, and enough fixing to get a working editor on Linux. It loads BSPs, it runs the movement, and it is a fork of [Fragsurf-2](https://github.com/Fragsurf/Fragsurf-2) rather than something I wrote from scratch.
