A shared org for the games and engines my friends and I build. The banner reads "not a real company", which is accurate.

**ROXOR** is a Roblox base project for games grounded in realism: a full character controller, melee and gun systems, health, stamina and a downed/revive loop, toggleable gore, ragdolls, a stylised UI framework and basic bot AI. Valve's games are the obvious influence.

**neosource** is Fragsurf ported to Unity 2022.3 and URP 14, with Linux editor support. A modernised Source engine for surf and bhop maps, in short.

There's also Goxot, a Godot project built on the Liblast framework, and a few smaller things.
