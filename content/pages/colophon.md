Static HTML, generated by one Python script with no dependencies. Content is Markdown with TOML frontmatter
in `content/`, so adding a project means dropping a file in a folder rather than editing code.

Type is Source Sans 3 and JetBrains Mono, both self-hosted. Colours are Catppuccin Mocha with `#ffbdbd`
doing most of the work, lifted straight off my desktop's base16 scheme.

No JavaScript anywhere on the site. No analytics, no cookie banner, no cookies to warn you about.

The graph on the front page is drawn with CSS borders and border-radius. Every URL is relative so the whole
thing survives being moved to a different path.

Hosted on GitHub Pages, served from furfag.lol. Built with an AI agent working off a brief I wrote, then I
read the diff.

Source is at [github.com/milotek/wst15](https://github.com/milotek/wst15). The 88x31s in the footer are mine,
drawn for this site. Send me yours.
