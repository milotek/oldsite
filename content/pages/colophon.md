## Build

Content lives in `content/` as markdown files with YAML front matter. One file per project, per post, per drawing. A single Python script, `build.py`, reads them and writes plain HTML into the repo root.

No dependencies, no node_modules, no build server. Python's standard library only, including a small YAML front matter parser and a markdown subset that covers the things I actually write. Every URL it emits is relative, so the site works at any base path, including `file://`.

## Hosting

GitHub Pages, serving static files straight out of the [repository](https://github.com/milotek/wst20). No CI step, because the built output is committed alongside its source.

## Type

[Source Sans 3](https://fonts.google.com/specimen/Source+Sans+3) for text, [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) for labels and code. Both self-hosted as subsetted woff2, so no requests leave for a font CDN.

## Colour

[Catppuccin Mocha](https://catppuccin.com/palette) as the base, with `#ffbdbd` as the accent throughout. The same scheme my desktop runs, which is less about consistency and more about me being unable to look at anything else now.

## Images

Project screenshots and drawings are re-encoded to WebP at build-prep time. The drawings were made in Procreate on an iPad Pro. The 88x31 buttons are generated by `tools/make-buttons.sh` with deliberately disabled antialiasing, because that's the only way they look right at that size.

## Analytics

None. No cookies, no trackers, no third-party requests of any kind.
