Static HTML, generated by one Python file with no dependencies. Content is Markdown with TOML frontmatter, in `content/`. Build output is committed, because GitHub Pages serves the repo directly.

One stylesheet. Zero JavaScript. Zero web fonts, so type falls back to whatever your system already has.

Colours are catppuccin mocha with `#ffbdbd` as the accent, taken from the theme I run on my own desktop.

Project screenshots and the drawings are salvaged from my old Carrd site and from the repos they belong to. The 88x31s are hand-drawn at actual size, apart from the two genuinely ancient ones.

Source is [on GitHub](https://github.com/milotek/wst21). There's [an RSS feed](../feed.xml) as well.
