**Stack.** Markdown and YAML in a `content/` folder, rendered by one Python script with Jinja2 and python-markdown. The output is committed and served by GitHub Pages. No JavaScript, no analytics, no cookies.

**Type.** Inter for text, JetBrains Mono for code and labels, Silkscreen for the 88x31 button. All self-hosted.

**Colour.** Catppuccin Mocha. Background #1e1e2e, text #cdd6f4, accent #ffbdbd.

**Buttons.** The classic gifs in the footer come from [the 88x31 GIF Collection](https://cyber.dabamos.de/88x31/). The milo tek one is mine; take it.

**Source.** [github.com/milotek/MLGSwag](https://github.com/milotek/MLGSwag). Adding a project or a post means adding a file.

**How it was made.** The first version was generated with Claude Code (Anthropic's coding agent) from a written brief, in a single unattended run. The brief fixed the facts it was allowed to use; the agent read my GitHub, the old carrd site and my file server for the rest, built the generator, checked screenshots at desktop and phone widths, and deployed it. There's a short [post](/blog/rebuilding-this-site/) about it.
