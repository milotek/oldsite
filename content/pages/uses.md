## Machine

NixOS on the desktop, Hyprland as the compositor, everything declared in [one flake](https://github.com/milotek/nixeljam) so a new box is a rebuild rather than an afternoon. A mini PC does the self-hosting, a small VPS owns the public ingress, Tailscale joins them up. A MacBook for work, because that's what work runs.

## Terminal

Ghostty, zsh, Zellij for panes. eza, fzf, zoxide and direnv are the four things I'd miss immediately. lazygit for anything more complicated than a commit.

## Editor

Neovim, configured through nvf so the config is Nix rather than a pile of Lua I'd stop maintaining.

## Languages

Python first for anything that runs as a service. TypeScript when there's a front end. C# and GDScript for games, Lua when the platform makes me. C++ when I want to suffer.

## Drawing

Procreate on an iPad Pro with an Apple Pencil, which has done every drawing on this site.

## Notes

Obsidian, in a git repo, synced by the same flake as everything else.
