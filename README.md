# wst13

My personal site. Static HTML generated by one Python script, served by GitHub Pages.

Live at <https://furfag.lol/wst13/>.

## Building

```sh
python3 build.py
```

No dependencies, no virtualenv, no lockfile. Python 3.11 or newer, because it uses
`tomllib` from the standard library. The generated HTML is committed, because Pages serves
flat files from the repo.

## Where things live

| Path | What it is |
| --- | --- |
| `content/site.toml` | Name, bio, links, the `now` list, the workspaces in the top bar |
| `content/projects.toml` | One `[[project]]` table each. `featured = true` gets a screenshot |
| `content/posts/*.md` | Blog posts. TOML front matter between `+++` fences |
| `content/art.toml` | The gallery. Each entry needs a matching pair in `img/art/` |
| `content/buttons.toml` | The 88x31 wall |
| `content/uses.toml` | The uses page, as groups of key/value rows |
| `content/colophon.md` | The colophon, as prose |
| `static/` | CSS, JS, fonts, favicon. Copied verbatim to `assets/` on build |
| `img/` | Every image, served straight from where it sits |
| `build.py` | The whole generator |

Everything at the repo root that is not in that table is build output. Do not edit it by
hand, it gets overwritten.

## Adding things

**A project.** Add a `[[project]]` table to `content/projects.toml`. Order in the file is
order on the page.

```toml
[[project]]
slug     = "thing"
name     = "thing"
year     = "2026"
tags     = ["python"]
repo     = "https://github.com/milotek/thing"
featured = false
blurb    = "One sentence. This is the only field that is compulsory alongside name and slug."
body     = """Markdown, optional, only shown when featured."""
```

**A post.** Drop a Markdown file in `content/posts/`. Name it `YYYY-MM-DD-slug.md`; the
date prefix is stripped to make the URL.

```markdown
+++
title = "a title"
date = "2026-09-04"
summary = "One line for the index and the feed."
tags = ["meta"]
+++

Body goes here.
```

**A drawing.** Put `<name>.webp` and `<name>_thumb.webp` in `img/art/`, then add a
`[[piece]]` table to `content/art.toml`.

**A button.** Put a real 88x31 file in `img/buttons/` and add a `[[button]]` table.

## Deploying

Push to `main`. The workflow in `.github/workflows/build.yml` reruns `build.py` and commits
the output if it changed, so editing a Markdown file on github.com is enough to publish.
