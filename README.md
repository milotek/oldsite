# wst15

My personal site. Static HTML, generated by `build.py` from Markdown and TOML in `content/`.

```sh
python3 build.py                       # regenerate the site into the repo root
python3 -m http.server 8715            # look at it
```

No dependencies, no build tooling, Python 3.11 or newer for `tomllib`. The output is committed because
GitHub Pages serves this repo as plain files.

## Adding things

- **A project or milestone** - drop a `.md` in `content/entries/`. TOML frontmatter between `+++` fences,
  Markdown body underneath. An entry with a body gets its own page at `/projects/<slug>/`; one without just
  appears on the log. `lane` is one of `main`, `games`, `systems`, `apps` and decides which rail it sits on.
  `sort` orders the log (newest first).
- **A blog post** - a `.md` in `content/posts/` with `title`, `date` and `summary`.
- **An 88x31 button** - PNG or GIF into `assets/buttons/`, then a `[[button]]` block in
  `content/buttons.toml`.
- **now / uses / colophon / art / the intro** - `content/pages/`.

Everything under `projects/`, `blog/`, `art/`, `now/`, `uses/`, `colophon/`, plus `index.html`, `404.html`
and `feed.xml` is generated. Don't edit those by hand, they get wiped on the next build.
