# milotek.dev

My personal site. Projects, a blog, drawings and a CV.

Static HTML generated by `build.py`. Stdlib Python only, no dependencies, no
package manager. Build output is committed because GitHub Pages serves the repo
directly.

## Building

```
python3 build.py
```

That clears the generated files, copies `static/` to `assets/`, and writes the
HTML, `feed.xml` and `404.html` into the repo root.

Every URL the build emits is relative, so the site works at the domain root or
under any subpath without configuration. The one exception is `404.html`, which
uses the absolute `url` from `content/site.toml` because it gets served at
arbitrary depths.

## Adding things

Nothing here needs `build.py` to be edited.

| I want to | Do this |
|---|---|
| add a project | drop a `.md` in `content/projects/` |
| write a post | drop a `.md` in `content/posts/` |
| add a drawing | put the image in `static/img/art/` (plus a thumbnail in `thumbs/`) and add a `[[piece]]` to `content/art.toml` |
| edit now / uses / colophon / cv | the matching `.md` in `content/pages/` |
| change a link, social or 88x31 | `content/site.toml` |

Content files are Markdown with TOML frontmatter between `+++` fences.

A project's frontmatter:

```toml
+++
title = "Thing"
year = "2026"
status = "in development"
weight = 30           # lower sorts first
featured = true       # also shows on the home page
tags = ["Python", "Flask"]
cover = "thing.png"   # from static/img/projects/
fit = "contain"       # "crop" (default) or "contain", for logos and banners
shots = ["a.jpg"]     # portrait screenshots instead of a cover
[[links]]
label = "repo"
href = "https://github.com/milotek/thing"
+++

Body copy in Markdown.
```

Art thumbnails are generated once, by hand:

```
magick full.jpg -resize 700x700\> -quality 78 -strip thumbs/full.jpg
```

## Layout

```
build.py          the generator
markdown.py       a small Markdown subset renderer
content/          everything the site says
static/           css, images, the CV pdf; copied to assets/ on build
```
