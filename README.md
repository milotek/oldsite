# milotek.dev

My personal site. Static HTML, generated by `build.py`, served by GitHub Pages.

Live at <https://furfag.lol/wst18/>.

## Adding things

Everything on the site is a file in `content/`. Nothing here needs `build.py` to be opened.

| I want to add | Do this |
| --- | --- |
| A project | Drop a `.md` in `content/projects/` with a `+++` header |
| A blog post | Drop a `.md` in `content/posts/` with a `title` and a `date` |
| A drawing | Add a `[[art]]` row to `content/art.toml`, put `<file>.webp` and `<file>-t.webp` in `assets/img/art/` |
| An 88x31 button | Add a row to `content/buttons.toml`, then run `tools/make_buttons.sh` if I need it drawn |
| A now / uses / colophon change | Edit the `.md` in `content/pages/` |
| Nav, socials, the intro, the rosters | Edit `content/site.toml` |

Then:

```sh
python3 build.py
git add -A && git commit -m "add thing" && git push
```

Output is committed to the repo root, because Pages serves plain files from `main`.

## A project file

```toml
+++
title    = "nixeljam"
group    = "systems"          # one of the [[groups]] ids in site.toml
year     = "2026 - now"       # optional
role     = "solo"
tagline  = "One line. It shows on the front page."
stack    = ["Nix", "NixOS"]
thumb    = "img/proj/nixeljam-thumb.webp"   # optional
slate    = "text shown when there is no thumb"
order    = 10                 # sorts the whole list
[[links]]
label = "source"
url   = "https://github.com/milotek/nixeljam"
[[images]]
src = "img/proj/nixeljam-1.webp"
alt = "Description for screen readers"
+++

Markdown body. The first paragraph is used as the preview blurb.
```

## Images

Thumbnails are 800x450, letterboxed onto `#181825` so every tile matches:

```sh
magick in.png -strip -resize 800x450 -background '#181825' -gravity center -extent 800x450 -quality 78 out.webp
```

Full-size shots are `-resize '1400x1400>' -quality 80`.

## Layout

```
build.py          the generator, stdlib only
content/          everything the site says
src/              style.css and select.js, copied to the root on build
assets/           fonts, images, buttons
tools/            make_buttons.sh
```
