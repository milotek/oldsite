# milo tek

Source for my site.
The whole thing is static HTML generated by one Python script, so the repo is the site.

## Adding things

Nothing here needs code changes.

- **A project**: add a `[[project]]` block to `content/projects.toml`.
- **A post**: drop a Markdown file with a `+++` TOML header into `content/posts/`.
- **A drawing**: add the images to `assets/img/art/` and an `[[art.piece]]` block to `content/art.toml`.
- **A button**: add an 88x31 PNG to `assets/img/buttons/` and a `[[wall]]` block to `content/buttons.toml`.
- **Anything else** (links, the now list, uses, colophon): `content/site.toml`.

Then:

```sh
python3 build.py
```

No dependencies, standard library only. Commit the output, GitHub Pages serves it.

## Images

`tools/shrink.sh` turns a source screenshot into the pair of WebPs the templates
expect (`name.webp` at 1400px and `name.thumb.webp` at 720px):

```sh
tools/shrink.sh shot.png assets/img/projects/thing-1
```

`tools/make-buttons.py` redraws the 88x31 buttons listed in
`content/buttons.toml`. Needs ImageMagick and the misc-fixed bitmap font.

## Layout

```
build.py            the generator, ~500 lines
content/            all the words
assets/css/         one stylesheet
assets/js/          search, lightbox
assets/fonts/       self-hosted Source Sans 3 + JetBrains Mono
tools/              image and button helpers
```

`index.json` is generated alongside the pages and is what the search box reads.
