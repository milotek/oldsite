# milotek.dev

My personal site, laid out as an engineering drawing sheet.

Static HTML generated by `build.py`, which uses nothing outside the Python
standard library. No JavaScript runs on any page.

## Adding things

Everything you'd want to change lives in `content/`. Nothing in there is code.

| File | What it holds |
| --- | --- |
| `content/site.toml` | Name, role, links, the sheet index that becomes the nav |
| `content/work.toml` | Current role, and the bullets under it |
| `content/projects.toml` | One `[[project]]` block per project, with `[[project.images]]` and `[[project.links]]` |
| `content/art.toml` | One `[[piece]]` per drawing |
| `content/buttons.toml` | The 88x31 buttons, plus how many empty slots to draw |
| `content/posts/*.md` | Blog posts. Markdown with YAML frontmatter, so they paste straight out of Obsidian |
| `content/pages/*.md` | `index`, `now`, `uses`, `colophon` |

Images go in `static/img/` and are referenced without that prefix, e.g.
`img/projects/lockyn_home.webp`. Gallery thumbnails are read from
`static/img/art/thumb/<same filename>`.

## Building

```
python3 build.py
```

It writes the site into the repository root and overwrites `assets/`,
`projects/`, `blog/`, `art/`, `now/`, `uses/`, `colophon/`, `index.html`,
`404.html` and `feed.xml`. GitHub Pages serves those files directly, so the
output is committed.
