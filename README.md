# wst19

My personal site. Static HTML generated by one dependency-free Python script, laid out as a transit line
diagram. Live at <https://furfag.lol/wst19/>.

## Adding things

Nothing below requires touching HTML or CSS.

| I want to add | Edit |
| --- | --- |
| a project, a game, a smaller thing | `content/projects.toml` |
| a drawing | `content/art.toml` (drop the image in `assets/img/art/`) |
| a post | a new `.md` in `content/posts/` |
| a link, a now item, a uses line, an 88x31 button | `content/site.toml` |

Then:

```shell
python3 build.py
```

That writes `index.html`, `blog/`, `feed.xml` and `404.html` into the repo root. GitHub Pages serves the
committed output, so the generated files are checked in on purpose.

## Content shapes

A project is a `[[project]]` table. `line` decides which section it lands in: `work`, `projects`, `games`
or `small`. Optional sub-tables:

```toml
[[project]]
id = "example"
title = "Example"
line = "projects"
period = "2026"
status = "active"          # small pill next to the date
private = true             # renders a "private repo" pill
summary = "One or two sentences."
details = ["Bullet.", "Another bullet."]
tech = ["Python", "Nix"]

[[project.link]]
label = "repo"
href = "https://example.com"
primary = true             # makes the title itself a link

[[project.shot]]
src = "assets/img/projects/example.webp"
caption = "what it is"
tall = true                # for phone screenshots
```

A post is Markdown with a small frontmatter block:

```markdown
---
title: the new site
date: 2026-09-05
summary: One line for the index and the feed.
---
```

The filename's `YYYY-MM-DD-` prefix is stripped to make the slug. Posts are plain Markdown, so the
folder can just as easily be a symlink into an Obsidian vault; the generator doesn't care where the
files came from.

## Assets

Fonts in `assets/fonts/` are Source Sans 3 and MesloLGS Nerd Font, subset locally with `fonttools` and
served as variable woff2. Images are webp except the animated ones. The 88x31 buttons in
`assets/buttons/` were rendered with headless Chrome; add your own by dropping a file in and appending a
`[[button]]` block.
