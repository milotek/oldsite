# milotek.dev

My personal site, laid out as a photographic contact sheet.

Static HTML generated by one dependency-free Python script. Content is TOML and
Markdown. GitHub Pages serves the repo root, so the generated HTML is committed.

## Adding things

Nothing below needs `build.py` to be opened.

| To add           | Do this                                                              |
| ---------------- | -------------------------------------------------------------------- |
| A project        | Drop a `.md` into `content/projects/` with a `+++` TOML header        |
| A note           | Drop a `.md` into `content/posts/`                                    |
| A drawing        | Add a `[[frame]]` block to `content/drawings.toml`                    |
| An 88x31         | Put the file in `static/buttons/`, add a `[[buttons]]` row to `content/site.toml` |
| A roll (category) | Add a `[[rolls]]` row to `content/site.toml`                          |

Then:

```sh
python3 build.py
```

Output goes to the repo root: `index.html`, `projects/`, `drawings/`, `notes/`,
`about/`, `colophon/`, `feed.xml`. Those paths are wiped and rewritten on every
build, so nothing hand-edited should live in them.

## Project frontmatter

```toml
+++
title  = "lakeback"
roll   = "work"        # must match a [[rolls]] id in site.toml
order  = 3             # position within the roll
year   = "2026"
kind   = "Game server infrastructure"
status = "in progress"
pick   = true          # draws the grease pencil ring
url    = "https://github.com/milotek/lakeback"
url_label = "github.com/milotek/lakeback"
blurb  = "One line, shown under the frame."
stack  = ["Kotlin", "Docker"]
frames = [ { img = "lakeback_1", caption = "match lobby" } ]
+++

Markdown body.
```

A project with no `frames` renders a typed slate showing its `stack` instead of
a picture, which is the honest option for work I cannot screenshot.

## Images

`img` values refer to files in `static/img/`. Every frame is 840x560, prepared
once by `assets_src/process.sh` from originals in `assets_src/raw/` (not
committed; `assets_src/fetch.sh` records where they came from).

## Deploying

Commit and push. Pages serves `main` from `/`. There is no CI step, because
there is no build to run on a server.
