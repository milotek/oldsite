now

Days: the Google Search app, London.

Recent pushes: habits (the wall-mounted tracker), nixeljam, and bullet penetration for neosource.

This site is brand new. The old carrd one had been "under construction" since 2024, so it's been retired.

uses

  • NixOS from my own flake, nixeljam. Hyprland on top, stylix for theming.
  • Catppuccin Mocha everywhere, with #ffbdbd swapped in as the accent. Rosé Pine cursor.
  • Ghostty and Zellij, both in MesloLGS Nerd Font.
  • Obsidian for notes. The vault is a git repo, and the posts here can come straight out of it.
  • Tailscale to reach my machines, Caddy in front of anything public.
  • A mini PC running copyparty as a file server for me and my friends.
  • An iPad Pro and Procreate for drawing.

colophon

Built from TOML and Markdown by one Python script, standard library only. One stylesheet. No JavaScript.

Colours are Catppuccin Mocha with #ffbdbd as the single accent, lifted from the pixeljam theme in my NixOS flake.

Type is Montserrat for sticker titles and Source Sans 3 for everything else, the same two fonts my desktop uses, self-hosted here.

The drawings are mine. The fox sticker is from my own files and I owe its artist a credit.

The classic 88x31 buttons come from the cyber.dabamos.de collection.

Hosted on GitHub Pages. Source is on GitHub, and the feed is RSS.
