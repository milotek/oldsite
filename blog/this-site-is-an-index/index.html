This site is an index

2026-09-04 · 575 words

metapythonstatic-sites

The old site was a carrd export.

It looked alright in 2024 and it had one real problem: everything I'd made was buried under three taps. You landed on a name, then a menu, then a section, and only then a project. Fine for a business card, useless for the thing it was supposed to be.

So the rebuild has exactly one idea behind it, and the idea is a search box.

Why a search box

I work on Google Search, on the app, on the backend side. Joke's on me, I know.

But spend enough time near a search product and you start to notice how much structure a site throws away. Projects, posts, drawings and pages are all just records with a title, a date, some tags and a bit of text. A normal portfolio splits them into separate pages and then makes you navigate between them.

This one puts them in one list and lets you filter it. Type lua and you get four projects and a modchart pack. Type godot and you get the EPQ game. Hit / from anywhere and the box takes focus.

Every result is a row in index.json, which the build script writes from the same data it uses to render the pages. It cannot drift out of sync, because there is nothing to sync.

The content system

The rule I set myself: I should never have to open a code file to update this site.

content/projects.toml holds one block per project. Six lines gets you a title, a year, some tags and a blurb. content/posts/ holds Markdown files with a TOML header, which is convenient because that's already how my Obsidian vault looks. Drawings, links, the now list, the uses page, the buttons: all TOML.

build.py reads that lot and writes the whole site. It's one file, no dependencies past the standard library, and it includes a small Markdown renderer because pulling in a package for one blog post felt worse than writing eighty lines.

Adding a project is a commit to a TOML file. That was the entire brief.

Colours

The accent is #ffbdbd, which is base0D in themes/pixeljam.nix in my NixOS config. The rest is Catppuccin Mocha.

So the site matches my desktop, my terminal, my editor and my bar, for the boring reason that they all read the same attrset. The rounding and border widths came out of the same file.

The honest bit

I didn't hand-write this one. I wrote a brief describing what I wanted, pointed a coding agent at my GitHub, my old site and my file server, and let it build the thing. It dug out fifteen drawings I'd forgotten were online and read every README I've written, which is more research than I'd have done myself.

The projects, the screenshots and the technical claims are real and came from repos you can go and check. The words are mine in style, not in typing. I'd rather say that on the site than have you work it out.

What isn't finished

The now page is seeded from what I've actually been pushing lately, but it's the page that goes stale fastest, so assume it's a week behind.

The 88x31 buttons are all mine or generic. There are three empty slots on the wall, and I want them filled with other people's. Send me one.

The CV linked in the header predates the Google job by a year. I know.
